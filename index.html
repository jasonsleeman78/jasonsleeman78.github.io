Hermes mail reader

Hermes mail reader is a private, personal tool. It reads the owner's own Gmail inbox so his personal assistant software can tell him about job listings and replies to his job applications. It is not offered to anyone else, and nobody else can sign in to it.

Privacy policy

Last updated 17 November 2026.

What it accesses

Read-only access to the owner's own Gmail account: messages and their contents. It cannot send, delete, move, label or mark any email, and it never tries to.

How the data is used

The tool reads new emails on a schedule. It uses them only to pick out job listings and application replies and report them to the owner. Email text is processed by an AI language model provider through its API to make that judgement. A short note of the newest email checked is kept so the next run starts from there.

Sharing

Data is not sold, shared with third parties for advertising, or used for any other purpose. It is not used to train AI models. The only people who see the results are the owner and the assistant software he runs.

Storage and deletion

Data is kept on the owner's private servers. Access can be removed at any time from the Google account's security settings under third-party access.

Google API data

Hermes mail reader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions go to the support email shown on the app's Google sign-in screen.
